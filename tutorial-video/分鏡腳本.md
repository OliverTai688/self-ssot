## 怎麼讀這份腳本

- **操作**：錄製腳本在真實介面上做的動作。引號內是實際會打進去的字。
- **旁白**：語音念的內容，同時就是畫面下方的字幕。
- **強調**：後製加的東西，例如局部放大、按鍵提示、框線。
- **秒**：估計值，依旁白字數（每秒約 4 個字）加操作時間算的，錄完才準。
- 標 ⚠ 的鏡頭，操作細節我還沒在真實介面上跑過，錄製時會先確認；跑不通就改腳本並告訴你。

介面上的文字（按鈕、選單項目）都是 10/3 從 showcase 預覽實際讀出來的。

## 全片共用設定

**示範資料**：改用一組「秋季展籌備」的教學資料，角色仍是宇星（你）與 Lily。現有 showcase 資料裡的私人句子與客戶名稱（BNI、柏翰、地政士等）全部拿掉。開場狀態固定如下：

| 項目 | 內容 |
|---|---|
| 日期 | 2026-09-12 週六（showcase 固定值） |
| 宇星的日誌 | 一張 Standup 卡片、兩三行工作筆記 |
| Lily 的日誌 | Standup，其中兩行是對宇星的請求 |
| 逾期請求 | Lily 問「週一拍攝要不要多加一台補光燈？」已逾期 2 小時 |
| 待我回覆（決策卡） | Lily 問「秋季展場地要選 A 還是 B？」選項 A · 松山文創、B · 華山 2 館，剩 18 小時 |
| 等對方回覆 | 宇星問「燈具預算上限可以到 15,000 嗎？」剩 3 小時 |
| 今日議題 | 「燈具廠商還沒回，要追」 |

**畫面**：1920×1080，深色主題。隱藏頂端黃色「預覽模式」橫幅與左下角開發工具圖示。

**每章結構**：標題卡 2.5 秒 → 內容 → 結尾卡 3 秒（列出本章重點）。

**旁白用字**：符號一律念中文，`#` 念「井字號」、`@` 念「小老鼠」、`?` 念「問號」、`!` 念「驚嘆號」、`~` 念「波浪號」。按鍵名稱 Enter、Tab、Shift 維持英文，語音合成念不好的話改用「換行鍵」「縮排鍵」。

## 這份腳本刻意沒有教的

| 功能 | 原因 |
|---|---|
| 在夥伴那一欄的某一行留言 | 9/25 發現對方欄有可編輯的缺陷，這次也沒確認留言入口；確認可用後可補進第 4 章 |
| 個人空間與圓展空間的切換 | 新成員第一天用不到，建議另做進階篇 |
| 切換視角（帳號選單） | 只有特定席位有，不是一般成員的功能；錄製時會用到，但不教 |
| 1:1 檢核、回顧、研究筆記模板 | 用法與 Standup 相同，第 3 章一句帶過 |
| 交易、時間線事件、決策物件 | 屬於金流與營運模組，建議放在各自模組的教學 |
| 回頭補寫舊日子（補記） | 進階情境 |

## 請你確認

1. 章節順序與每章的範圍對不對，有沒有該教沒教、或不該教的。
2. 旁白語氣：現在是口語、第二人稱「你」。要更正式或更輕鬆請說。
3. 示範情境用「秋季展籌備」可以嗎，或要換成更貼近你們實際工作的情境。
