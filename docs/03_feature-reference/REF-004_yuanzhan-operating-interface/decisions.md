## D09 — 2026-09-13 自主 UI 階段授權與互動修正

使用者明確批准完成整個 PLN-070 UI 階段，允許因適用性自主下載套件；既定範圍內自主選元件、客製與驗證，只有產品行為或範圍改變才詢問。每個完整情境交付可操作預覽、showcase／empty 結果與限制後繼續。

- 公司日誌直接即時分享，不需按發布／記錄才讓同事看見；舊稿件流程描述以本決定為準。UI 階段在同一記憶體 store 的成員視角立即反映，尚非不同瀏覽器的真實同步。
- 作者編輯日誌正文，任務負責人更新進度，其他成員透過留言協作。管理者額外操作須明列；不默認能改他人正文。
- 財務直接編輯／貼上／排序篩選／批次操作，並保留公式。首版實作算術、括號、A1 儲存格引用與 SUM／AVERAGE／MIN／MAX；未知函數、循環引用與無效參照顯示錯誤。
- 延續原型版面，套用目前產品的 tokens／視覺系統。
- 手機完整支援日常協作，複雜財務與 Evidence 整理以桌機為主。
- 選型從現有元件、shadcn/UI、React Aria、Magic UI 按需要取用，再組合為圓展元件；不用為使用三套而重複相同基礎操作。
- 不變更正式 auth／DB／部署／公開分享。此 UI 階段授權取代逐頁等待批准的舊預設，畫面狀態仍要可追溯。

UI 模擬的管理者額外操作與公式範圍已明列於 ARC-040 第 6–7 節；不構成正式公司財務、人事或授權制度。
