資料模型

Request { id, from, to, sourceLine, kind: ask|decision, options?, sentAt, seenAt?, firstReplyAt?, resolvedAt?, deferReason? }
逾期條件：!firstReplyAt && now - sentAt > 24h

「回覆」的定義

文字回覆、選了決策卡的選項，或按「收到，晚點處理」都算回覆。回覆後計時停止；議題本身要等對方按「已解決」才算結束。

提醒節奏

16h 推播給回覆方 → 24h 雙方都出現紅色橫幅 → 之後每 4h 再推播一次，直到有人回覆。橫幅可以收合，但每次換頁都會再出現。
